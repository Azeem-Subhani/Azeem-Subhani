### 👨‍💻 About me

I'm a full-stack engineer with **4+ years** of experience building secure web portals, REST and GraphQL APIs, cross-platform mobile apps and AI-enabled workflows. I'm currently a **Senior Software Engineer at Cinnova Technologies** in Lahore.

| | |
|:--|:--|
| 🔐 **Access control first** | Role-based access, scoped API keys and JWT/Cognito auth from day one |
| 🧱 **Data that can't drift** | PostgreSQL constraints and transactions keep payments and records in step |
| 🤖 **AI with a human in the loop** | Models propose, people confirm. Every tool call is validated, rate-limited and audit-logged |
| 🚀 **Safe delivery** | Automated tests in CI, code review and GitHub Actions deployments |
